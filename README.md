# 客序 AI · Client Journey Studio

一个可独立运行的客户旅程与咨询协作原型。它用合成数据展示从客户咨询、信息记录、跟进任务到人工接管的工作闭环。

> **演示说明：** 所有机构、人物、会话、分数和业务数据均为虚构。咨询回复由本地关键词规则离线模拟，**不连接真实 AI**、外部 API、数据库或客服系统。本项目用于展示产品流程和前端状态设计，不代表生产服务。

## 体验路径

1. 在「总览」查看客户信号、待办任务和接管数量。
2. 进入「客户 360」，切换客户，查看阶段、意向和旅程时间线。
3. 在「咨询工作台」发送消息，观察离线模拟回复。点击「人工接管」后，自动回复暂停，可从独立输入框发送顾问演示回复。
4. 从咨询生成基于最近客户消息的任务草稿，编辑确认后创建；也可在「跟进任务」自行创建并标记完成。
5. 刷新页面检查本地状态；点击侧栏「重置演示数据」可恢复初始样例。

## 本地运行

需要 Node.js 22 或更新版本，无第三方运行依赖。

```bash
npm start
```

打开 `http://127.0.0.1:4175`。运行测试：

```bash
npm test
```

浏览器端关键路径测试使用 Playwright。首次运行先安装开发依赖和 Chromium：

```bash
npm install
npx playwright install chromium
npm run test:browser
```

## 实现说明

- `src/demo-data.js`：三位虚构客户及初始会话、任务和时间线。
- `src/domain.js`：纯函数管理消息、模拟回复、任务和接管；业务状态与界面分离。
- `src/app.js`：四个工作区视图、交互与浏览器本地保存。用户输入统一进行 HTML 转义。
- `scripts/serve.mjs`：只提供演示页面所需的静态文件。

浏览器状态保存在 `localStorage`。演示回复和意向分数都不能用于真实业务判断；若扩展为正式产品，需要独立实现身份验证、服务端存储、权限、模型接入、人工接管的可靠消息队列，以及真实数据治理。
